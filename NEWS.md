# galick 0.1.0

First release candidate; not yet published on CRAN.

## Highlights

- Validate, diagnose and repair genotype tables, marker maps and VCF files.
- Convert CSV and HapMap data to VCF, and extract, export or merge genotypes.
- Run Beagle phasing and imputation with chromosome workflows, logs and run records.
- Simulate linked breeding genotypes, evaluate imputation configurations and
  design low-density SNP panels with separate tuning and test samples.

## Fixes

- Windows PLINK discovery distinguishes the genetics tool from PuTTY's SSH client.
